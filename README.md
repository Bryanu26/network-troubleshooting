# Network Troubleshooting

A collection of real-world troubleshooting cases encountered while working with networking, structured cabling, AV systems, fiber optics, surveillance, and homelab environments.

## Categories

- Networking
- Fiber Optics
- Structured Cabling
- AV Systems
- Surveillance
- Systems
- Homelab

## Goal

This repository documents real production issues, the troubleshooting process, root cause analysis, and lessons learned. Every case included here was based on actual field experience or lab validation.

## Case Format

Each troubleshooting case includes:

- Environment
- Symptoms
- Troubleshooting Steps
- Root Cause
- Solution
- Lessons Learned
