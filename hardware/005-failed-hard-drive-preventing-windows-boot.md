Failed Hard Drive Preventing Windows Boot

## Environment

HP Omen desktop running Windows.

## Symptoms

* Computer powered on successfully.
* Windows failed to boot.
* The system could not load the operating system.
* Hardware appeared to function normally.

## Troubleshooting

* Verified BIOS detected system hardware.
* Checked boot configuration.
* Tested the storage device.
* Installed a replacement NVMe SSD.
* Performed a clean installation of Windows 11.
* Verified successful boot after installation.

## Root Cause

The original storage device had failed, preventing Windows from loading correctly.

## Solution

Replaced the failed storage device with a new NVMe SSD, installed Windows 11, and verified normal system operation.

## Lessons Learned

* A computer that powers on but does not boot is not necessarily experiencing a motherboard or GPU failure.
* Always verify storage health before replacing major hardware components.
* A clean operating system installation on known-good storage is an effective way to isolate storage-related issues.
