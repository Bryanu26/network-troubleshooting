# Smart TV Wi-Fi Disabled with No Available Networks

## Environment

Residential AV system with a Smart TV connected to a home wireless network.

## Symptoms

* The TV did not display any available Wi-Fi networks.
* The network settings indicated that Wi-Fi needed to be enabled.
* The interface did not clearly indicate where to enable the Wi-Fi adapter.
* Other devices on the home network were operating normally.

## Troubleshooting

* Verified the home wireless network was operational.
* Confirmed the issue was isolated to the TV.
* Navigated through the TV's network settings.
* Located the hidden Wi-Fi enable/disable option.
* Enabled the wireless adapter.
* Scanned for available wireless networks.
* Connected the TV to the correct Wi-Fi network and verified internet access.

## Root Cause

The TV's wireless adapter had been disabled, preventing the device from scanning for or displaying available Wi-Fi networks.

## Solution

Enabled the TV's Wi-Fi adapter through the network settings. Once the adapter was re-enabled, the TV detected nearby wireless networks and successfully connected to the internet.

## Lessons Learned

* If a TV does not display any wireless networks, verify that the Wi-Fi adapter is enabled before troubleshooting the network.
* Some Smart TVs hide the Wi-Fi enable/disable setting, making the issue appear to be a network failure.
* Always isolate whether the issue is with the client device or the network infrastructure before replacing equipment.
